# Cutsceneless maps for SourceSpeedrunMod

Half-Life 2 maps with the long scripted scenes cut, packaged for
[SourceSpeedrunMod](https://github.com/mistersliva/SourceSpeedrunMod).
The patch itself is by **peng**; this repository only hosts it so the launcher
can download it separately from the mod.

## Install

- **With the launcher:** tick *Also download Cutsceneless maps* before installing
  the mod, or use *Settings → Optional content → Cutsceneless maps → Install*.
  Then switch it on in the game: *Settings → Game → Cutsceneless maps*.
- **By hand:** download the zip from
  [Releases](https://github.com/mistersliva/SSM-Cutsceneless/releases) and unpack
  it so the maps end up in `<mod folder>\cutsceneless\maps`.

Start a new game after switching it on or off: saves made on the other maps do
not load correctly.

Half-Life 2 (Steam) is required. Half-Life 2 and its maps are © Valve.
